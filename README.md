# Seus dados, suas regras: privacidade digital

Landing page e folder com dicas de TI sobre **privacidade e dados pessoais**, relacionando os conceitos de **Ética Hacker** ao problema proposto no PBL:

> Como auxiliar as pessoas a conhecerem e utilizarem melhor a tecnologia?

**Site:** https://victorrizzotto.github.io/privacidade-digital/

## Dica de TI

> Antes de tocar em “Permitir”, pergunte: esse app precisa mesmo disso?

| Caminho | O que é |
